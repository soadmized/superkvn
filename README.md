# SUPERKVN - (почти) неубиваемый kvn
[![GitHub Repo stars](https://img.shields.io/github/stars/soadmized/superkvn-landing?logo=github&style=flat-square)](https://github.com/soadmized/superkvn)
---
**SUPERKVN** - проект, который поднимает плохо детектируемое защищенное соединение с сервером через TLS и vless.

## 🚩 Предусловия  🚩
Перед развертываением проекта у вас уже должны быть:
- Сервер (`vps`/`dedicated`) с unix-подобной ОС, `docker` и `cron` (для автопродления SSL), расположенный за пределами РФ
- Зарегистрированный домен, указывающий на сервер (`A-запись`/`A-record`)
- Порты `80` и `443` открыты

## Особенности
SUPERKVN автоматически поднимает сайт, nginx, 3x-ui, получает SSL-сертификаты от Let’s Encrypt и создает настроенный входящий узел (inbound) в 3x-ui.
SUPERKVN создает плохо детектируемое защищенное соединение с сервером: для провайдера это выглядит как обычный HTTPS-трафик на ваш абсолютно нормальный рабочий сайт с действующими сертификатами.

## Как использовать

### 1. Клонируем репозиторий
```bash
git clone https://github.com/soadmized/superkvn.git
cd superkvn
```

### 2. Настройка переменных окружения
Скопируйте `.env.dist` в `.env` и заполните значения:
```bash
cp .env.dist .env
nano .env
```
**Важные параметры:**
- `DOMAIN`: Ваш домен (должен быть заранее направлен на IP сервера).
- `EMAIL`: Для уведомлений от Let's Encrypt.
- `UI_PORT`, `UI_DUMMY_PATH`, `UI_PATH`: Настройки для скрытия панели управления.

### 3. Быстрый запуск (рекомендуется)
Все шаги (подъем HTTP, выпуск SSL, настройка 3x-ui и перезапуск на HTTPS) выполняются одной командой:
```bash
make deploy
```

### 4. Где взять данные для подключения?
После выполнения `make deploy` все необходимые данные будут сохранены в файл `~/creds.txt` (в домашней директории пользователя):
- Логин и пароль от панели 3x-ui.
- Ссылка на панель управления.
- Ссылка `vless://` для импорта в клиент (V2Ray, Shadowsocks и др.).

## Ручное управление (если не использовать deploy)

### Шаг 1: Поднимаем Nginx (только HTTP)
```bash
make nginx-http
```

### Шаг 2: Получение SSL-сертификата
```bash
make ssl-init
```

### Шаг 3: Настройка 3x-ui
Генерация пароля, создание инбаунда и экспорт ссылки:
```bash
make 3xui-init
```

### Шаг 4: Перезапуск с HTTPS
```bash
make restart
```

---

## Полезные команды
- `make logs`: Просмотр логов Nginx.
- `make ssl-renew`: Ручное обновление сертификатов.
- `make cron-install`: Установка автопродления сертификатов в crontab.
- `make down`: Остановка всех контейнеров.
- `make gen-pass`: Сгенерировать новый пароль для админки.
